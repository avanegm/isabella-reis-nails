# Isabella Reis Nails — Landing Page

Primeira versão de uma landing page premium para uma Nail Designer em Sorocaba, pensada para receber tráfego vindo do Instagram.

## Conceito

- estética feminina premium em rosa, pink e lilás, seguindo a referência visual aprovada;
- foco em conversão: **Agendar → WhatsApp → Instagram**;
- seção de trabalhos para substituir pelos conteúdos reais do Instagram;
- CTA final de agendamento;
- layout responsivo, com prioridade para celular.

## Rodar localmente

```bash
npm install
npm run dev
```

## Antes de publicar

Edite `src/App.tsx` e troque:

- `LINKS.booking` pelo link real de agendamento;
- `LINKS.whatsapp` pelo WhatsApp real;
- `LINKS.instagram` pelo Instagram real.

As imagens em `public/images/work-*.svg` são placeholders de desenvolvimento. Substitua pelos trabalhos reais da Isabella.

A imagem `design-reference.png` é apenas a referência visual usada para orientar o projeto e não é usada diretamente na página.
